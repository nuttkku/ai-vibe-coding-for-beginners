# LAB-02 | คุยกับ AI ครั้งแรก

**Session:** 1.3 | **เวลา:** 11:30 - 12:00 น. | **ระยะเวลา:** ~30 นาที

> ผลลัพธ์: ผู้เรียนส่งข้อความให้ AI และได้รับการตอบกลับสำเร็จครั้งแรก

---

## สิ่งที่ต้องมีก่อนเริ่ม

- [ ] VS Code เปิดอยู่
- [ ] Cline ติดตั้งและตั้งค่าแล้ว (จาก LAB-01)
- [ ] Ollama กำลังรันอยู่

---

## ส่วนที่ 1: ตรวจสอบว่า Ollama พร้อมทำงาน

Ollama ต้องรันอยู่เบื้องหลัง ก่อนที่ Cline จะคุยกับ AI ได้

1. ดูที่ **System Tray** (มุมล่างขวาของ Desktop)
2. ควรเห็นไอคอนของ Ollama อยู่ที่นั่น
3. ถ้าไม่เห็น ให้เปิด Ollama จาก Start Menu

> **เช็คด้วย PowerShell ได้เลย:** เปิด PowerShell แล้วพิมพ์ `ollama list` — ถ้าเห็นรายการโมเดล แสดงว่า Ollama พร้อม

---

## ส่วนที่ 2: เปิด Cline ใน VS Code

1. เปิด VS Code (ถ้ายังไม่ได้เปิด)
2. มองที่แถบด้านซ้าย (Activity Bar) จะเห็นไอคอนของ Cline
3. คลิกที่ไอคอน Cline
4. แผงของ Cline จะเปิดขึ้นด้านขวา (หรือด้านล่าง)

> **ถ้าหาไม่เจอ:** กด `Ctrl + Shift + P` แล้วพิมพ์ `Cline` เลือก "Cline: Open"

---

## ส่วนที่ 3: ทดสอบคุยกับ AI

### ทดสอบที่ 1 — ทักทาย AI

1. คลิกที่ช่องข้อความในแผง Cline
2. พิมพ์ข้อความต่อไปนี้แล้วกด **Enter** หรือคลิกปุ่มส่ง:

```
สวัสดีครับ ช่วยแนะนำตัวเองหน่อยได้ไหม? และบอกหน่อยว่าตอนนี้คุณคือ AI Model อะไร?
```

3. รอดู AI ตอบกลับ (อาจใช้เวลา 5-15 วินาทีสำหรับคำตอบแรก)

**ผลที่ควรได้:** AI ตอบกลับเป็นข้อความ อธิบายว่าตัวเองคือ Qwen2.5-Coder

---

### ทดสอบที่ 2 — ถาม AI เรื่องโค้ด

พิมพ์ข้อความนี้:

```
ช่วยอธิบายหน่อยว่า HTML คืออะไร? อธิบายแบบง่ายๆ สำหรับครูที่ไม่ได้เขียนโค้ดมานาน
```

**ผลที่ควรได้:** AI อธิบาย HTML เป็นภาษาเข้าใจง่าย ไม่ใช้ศัพท์เทคนิคมากเกินไป

---

### ทดสอบที่ 3 — ขอให้ AI สร้างโค้ด

พิมพ์ข้อความนี้:

```
ช่วยสร้างโค้ด HTML สั้นๆ ที่แสดงข้อความ "สวัสดีโลก!" บนหน้าจอได้ไหม?
```

**ผลที่ควรได้:** AI สร้างโค้ด HTML ให้พร้อมคำอธิบาย

---

## ส่วนที่ 4: ทำความเข้าใจ UI ของ Cline

```
┌─────────────────────────────────────┐
│  Cline                         ⚙️   │  ← ไอคอน Settings
├─────────────────────────────────────┤
│                                     │
│  💬 ข้อความจาก AI จะแสดงที่นี่     │
│                                     │
│  🔧 Cline จะขอ Permission ก่อน      │
│     ทำอะไรกับไฟล์ในเครื่อง         │
│                                     │
├─────────────────────────────────────┤
│  พิมพ์ข้อความที่นี่...         [ส่ง] │  ← ช่องพิมพ์
└─────────────────────────────────────┘
```

**สิ่งสำคัญที่ต้องรู้:**
- เมื่อ Cline จะสร้างหรือแก้ไขไฟล์ มันจะถามขออนุญาตก่อน
- คลิก **Approve** เพื่ออนุมัติ หรือ **Reject** เพื่อปฏิเสธ
- เราควบคุมได้ตลอดเวลา ไม่ต้องกลัว

ก่อนพักกลางวัน ตรวจสอบ:

- [ ] AI อธิบายตัวเองและตอบคำถามได้
- [ ] AI สร้างโค้ด HTML ให้เมื่อขอ

**ถ้าสำเร็จทั้ง 3 ข้อ — ยินดีด้วย! คุณคุยกับ AI ครั้งแรกสำเร็จแล้ว! 🎉**

## แก้ปัญหาที่พบบ่อย

| ปัญหา | วิธีแก้ |
|---|---|
| Cline ขึ้น Error สีแดง | ตรวจสอบว่า Ollama กำลังรันอยู่ |
| AI ตอบช้ามาก (> 1 นาที) | ปกติสำหรับคำตอบยาว รอได้เลย |
| AI ตอบเป็นภาษาอังกฤษ | เพิ่มในข้อความว่า "ตอบเป็นภาษาไทยด้วยนะ" |
| Cline ไม่เปิด Panel | ลอง Restart VS Code |
