# LAB-03 | ศิลปะการสั่งการ AI (Prompt Engineering)

**Session:** 1.4 | **เวลา:** 13:00 - 14:00 น. | **ระยะเวลา:** ~1 ชั่วโมง

> ผลลัพธ์: ผู้เรียนสามารถเขียน Prompt ที่ดีได้ และเห็นความแตกต่างระหว่าง Prompt ที่ดีกับไม่ดี

---

## แนวคิดหลัก: Prompt คืออะไร?

**Prompt** = ข้อความที่เราพิมพ์บอก AI ว่าต้องการอะไร

ลองนึกภาพว่า AI เหมือนช่างฝีมือที่เก่งมาก แต่ถ้าเราสั่งงานไม่ชัด งานที่ได้ก็จะไม่ตรงใจ

---

## โครงสร้าง Prompt ที่ดี

```
┌──────────────────────────────────────────────────┐
│  Prompt ที่ดีมี 3 ส่วน                           │
│                                                  │
│  1. บริบท (Context)                              │
│     "ฉันกำลังสร้างเว็บสำหรับโรงเรียน..."         │
│                                                  │
│  2. เป้าหมาย (Goal)                              │
│     "...ช่วยสร้างหน้าแรกที่แสดงชื่อโรงเรียน..."  │
│                                                  │
│  3. ข้อจำกัด (Constraint)                        │
│     "...ใช้สีน้ำเงินและขาว ภาษาไทย"              │
└──────────────────────────────────────────────────┘
```

---

## เปรียบเทียบ: Prompt ที่ไม่ดี vs Prompt ที่ดี

### ตัวอย่างที่ 1: หน้าเว็บโรงเรียน

| ❌ Prompt ที่ไม่ดี | ✅ Prompt ที่ดี |
|---|---|
| "สร้างเว็บไซต์" | "สร้างหน้าเว็บ HTML หน้าเดียว สำหรับโรงเรียนประถมในชนบท แสดงชื่อโรงเรียน ข้อความต้อนรับ และเบอร์โทรศัพท์ ใช้สีน้ำเงินและขาว ภาษาไทย" |

---

### ตัวอย่างที่ 2: ฟอร์มรับสมัคร

| ❌ Prompt ที่ไม่ดี | ✅ Prompt ที่ดี |
|---|---|
| "ทำฟอร์ม" | "สร้างฟอร์ม HTML รับสมัครนักเรียน มีช่องกรอก: ชื่อ-นามสกุล, ชั้นที่สมัคร (ป.1-ป.6), เบอร์โทรผู้ปกครอง และมีปุ่ม 'ส่งใบสมัคร' สีเขียว" |

---

### ตัวอย่างที่ 3: แก้ปัญหา

| ❌ Prompt ที่ไม่ดี | ✅ Prompt ที่ดี |
|---|---|
| "แก้ Error" | "โค้ดนี้ Error ว่า 'SyntaxError: Unexpected token' ที่บรรทัด 15 ช่วยหาสาเหตุและแก้ให้ด้วย: [วาง Error message ที่นี่]" |

## แบบฝึกหัด — ทำใน Cline

เปิด Cline แล้วลองทำแบบฝึกหัดต่อไปนี้ตามลำดับ

---

### แบบฝึกหัดที่ 1: ปรับ Prompt จากไม่ดีให้ดีขึ้น

**ขั้นตอน:**
1. เปิด Cline
2. ส่ง Prompt ไม่ดีก่อน แล้วดูผลลัพธ์:
   ```
   ทำปฏิทิน
   ```
3. ดูว่า AI ตีความว่าอย่างไร
4. จากนั้นส่ง Prompt ที่ดีกว่า:
   ```
   สร้างตารางปฏิทิน HTML แบบง่าย แสดงเดือนมิถุนายน 2568 
   มีวันจันทร์ถึงอาทิตย์เป็นหัวตาราง วันหยุดเสาร์อาทิตย์ให้ไฮไลท์สีแดงอ่อน 
   ตัวอักษรภาษาไทย
   ```
5. เปรียบเทียบผลลัพธ์ทั้งสอง

**คำถามชวนคิด:** ผลลัพธ์ต่างกันอย่างไร? อะไรทำให้ Prompt ที่สองดีกว่า?

---

### แบบฝึกหัดที่ 2: เขียน Prompt บรรยายโปรเจกต์ตัวเอง

**ขั้นตอน:**
1. นึกถึงสิ่งที่อยากสร้างจริงๆ (เว็บโรงเรียน, ตารางสอน, ใบงาน, ฯลฯ)
2. เขียน Prompt โดยใช้โครงสร้าง 3 ส่วน:

```
บริบท: ฉันเป็น[บทบาท] กำลังสร้าง[สิ่งที่สร้าง] สำหรับ[กลุ่มเป้าหมาย]
เป้าหมาย: ช่วยสร้าง[รายละเอียดชิ้นงาน]
ข้อจำกัด: ใช้[ภาษา/สี/สไตล์]
```

**ตัวอย่างจากครูคนหนึ่ง:**
```
บริบท: ฉันเป็นครูวิทยาศาสตร์ ป.5 กำลังสร้างเว็บสำหรับนักเรียน
เป้าหมาย: ช่วยสร้างหน้าเว็บ HTML ที่มีควิซ 5 ข้อเรื่องระบบสุริยะ 
          แต่ละข้อมี 4 ตัวเลือก มีปุ่มตรวจคำตอบ
ข้อจำกัด: ภาษาไทย ดีไซน์สีน้ำเงินฟ้าเหมือนอวกาศ
```

3. ส่ง Prompt ที่เขียนให้ Cline แล้วดูผลลัพธ์

---

### แบบฝึกหัดที่ 3: การสั่ง Iterate (ปรับปรุงต่อเนื่อง)

**นี่คือทักษะสำคัญที่สุด!** Vibe Coding ไม่ใช่แค่สั่งครั้งเดียวแล้วได้ผลสมบูรณ์ แต่คือการ**ปรับปรุงซ้ำๆ**

**ขั้นตอน:**
1. ส่ง Prompt แรกสร้างอะไรสักอย่าง เช่น:
   ```
   สร้างหน้าเว็บ HTML แสดงรายชื่อวิชาในหลักสูตร ป.4 ภาษาไทย
   ```
2. ดูผลลัพธ์ แล้วสั่งปรับปรุง:
   ```
   ดีแล้ว ช่วยเพิ่มไอคอนอีโมจิหน้าแต่ละวิชาด้วย และเปลี่ยนพื้นหลังเป็นสีเหลืองอ่อน
   ```
3. สั่งปรับอีกครั้ง:
   ```
   ช่วยทำให้ตัวหนังสือใหญ่ขึ้น และเพิ่มชื่อโรงเรียนที่หัวหน้าเพจด้วย
   ```

**สังเกตว่า:** เราไม่ได้สั่งทุกอย่างพร้อมกัน แต่ค่อยๆ ปรับ — นี่คือสไตล์การทำงานของ Vibe Coding

## เทคนิคพิเศษ

### เทคนิค 1: บอก "ฉันต้องการ" ไม่ใช่ "ทำให้"
- ❌ "ทำปุ่มสีแดง"
- ✅ "ฉันต้องการปุ่มที่มีสีแดงสด เมื่อ Hover แล้วเข้มขึ้น และมีข้อความ 'ส่งงาน'"

### เทคนิค 2: ให้ตัวอย่าง
```
สร้างการ์ดแสดงข้อมูลนักเรียน ตัวอย่างข้อมูล: ชื่อ "สมชาย ใจดี" ชั้น ป.5/2 
```

### เทคนิค 3: บอกว่าไม่ต้องการอะไร
```
สร้างเว็บแสดงตารางสอน ไม่ต้องมี JavaScript ใช้แค่ HTML และ CSS
```

### เทคนิค 4: ขอคำอธิบายด้วย
```
สร้าง HTML สำหรับหน้าแรกเว็บโรงเรียน และอธิบายสั้นๆ ว่าแต่ละส่วนทำอะไร
```

## บทสรุป

```
Prompt ที่ดี = บริบท + เป้าหมาย + ข้อจำกัด

ยิ่งชัดเจน → ยิ่งได้ผลลัพธ์ตรงใจ
ไม่ได้ผล → สั่งปรับปรุงต่อ (ไม่ใช่เริ่มใหม่!)
```
