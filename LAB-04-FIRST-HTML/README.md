# LAB-04 | สร้างหน้าเว็บแรกด้วย AI

**Session:** 1.5 | **เวลา:** 14:00 - 15:00 น. | **ระยะเวลา:** ~1 ชั่วโมง

> ผลลัพธ์: ผู้เรียนมีหน้าเว็บแนะนำตัวเองที่สร้างโดย AI และสามารถสั่งแก้ไขได้

---

## เราจะสร้างอะไร?

หน้าเว็บ HTML แนะนำตัว ประกอบด้วย:
- ชื่อและตำแหน่ง
- คำอธิบายสั้นๆ เกี่ยวกับตัวเอง
- วิชาที่สอน / ความสนใจ
- ข้อมูลติดต่อ

---

## ส่วนที่ 1: เตรียมโฟลเดอร์โปรเจกต์

**1.1 สร้างโฟลเดอร์ใหม่**
1. เปิด File Explorer (Windows Explorer)
2. ไปที่ที่ต้องการเก็บงาน เช่น Desktop หรือ Documents
3. คลิกขวา → **New** → **Folder**
4. ตั้งชื่อว่า `my-first-webpage`

**1.2 เปิดโฟลเดอร์ใน VS Code**

**วิธีที่ 1 (ง่ายที่สุด):**
1. เปิด VS Code
2. คลิก **File** → **Open Folder**
3. เลือกโฟลเดอร์ `my-first-webpage` ที่เพิ่งสร้าง
4. คลิก **Select Folder**

**วิธีที่ 2 (ลากวาง):**
1. ลากโฟลเดอร์ `my-first-webpage` วางลงในหน้าต่าง VS Code

**ผลที่ควรเห็น:** แถบด้านซ้ายของ VS Code แสดงชื่อโฟลเดอร์ `MY-FIRST-WEBPAGE`

---

## ส่วนที่ 2: สั่งให้ AI สร้างหน้าเว็บ

**2.1 เปิด Cline**
1. คลิกไอคอน Cline ที่แถบซ้ายของ VS Code

**2.2 ส่ง Prompt แรก — สร้างไฟล์ HTML**

คัดลอก Prompt ด้านล่างนี้และปรับใส่ข้อมูลของตัวเองก่อนส่ง:

```
ฉันเป็นครู[วิชาที่สอน] ที่โรงเรียน[ชื่อโรงเรียน]
ช่วยสร้างไฟล์ชื่อ index.html เป็นหน้าเว็บแนะนำตัว มีดังนี้:
- ชื่อ-นามสกุล: [ใส่ชื่อตัวเอง]
- ตำแหน่ง: ครู[วิชาที่สอน]
- โรงเรียน: [ชื่อโรงเรียน]
- คำทักทายสั้นๆ ประมาณ 2 ประโยค
- รายการวิชาที่สอน 3-4 วิชา
- อีเมล: [อีเมลของตัวเอง]

ดีไซน์สวยงาม สีหลักเป็นสีน้ำเงิน ตัวอักษรภาษาไทย ไม่ต้องใช้ JavaScript
```

**2.3 อนุมัติการสร้างไฟล์**

เมื่อ Cline แจ้งว่าจะสร้างไฟล์ `index.html`:
1. ดูตัวอย่างโค้ดที่ Cline แสดง
2. คลิก **Approve** เพื่ออนุญาต

**ผลที่ควรเห็น:** ไฟล์ `index.html` ปรากฏในแถบซ้ายของ VS Code

---

## ส่วนที่ 3: เปิดดูผลลัพธ์ในเบราว์เซอร์

**วิธีที่ 1 — เปิดตรงๆ**
1. ในแถบซ้ายของ VS Code คลิกขวาที่ไฟล์ `index.html`
2. เลือก **"Reveal in File Explorer"**
3. ดับเบิลคลิกที่ `index.html` ในหน้าต่าง Explorer
4. Browser จะเปิดขึ้นและแสดงหน้าเว็บ

**วิธีที่ 2 — ผ่าน Live Preview (ถ้าติดตั้ง Extension)**
1. ค้นหา Extension ชื่อ "Live Preview" ใน VS Code แล้วติดตั้ง
2. คลิกขวาที่ไฟล์ `index.html` เลือก **"Show Preview"**

---

## ส่วนที่ 4: Loop การแก้ไข — ปรับแต่งด้วย AI

นี่คือหัวใจของ Vibe Coding! ดูผลลัพธ์ แล้วสั่งแก้ไข ทำซ้ำๆ

### รอบที่ 1: ปรับสีและสไตล์

กลับมาที่ Cline แล้วส่ง Prompt:

```
หน้าเว็บดูดีแล้ว แต่ช่วยปรับแต่งนิดหน่อย:
1. เพิ่มเส้นขีดใต้ชื่อให้สวยขึ้น
2. ทำให้รายการวิชาแสดงเป็น Card แทนแบบ list
3. เพิ่ม emoji ที่เหมาะสมหน้าหัวข้อแต่ละส่วน
```

คลิก Approve แล้ว Refresh browser ดูผล

### รอบที่ 2: เพิ่มเนื้อหา

```
ช่วยเพิ่ม section ใหม่ "ความสนใจส่วนตัว" ใต้ส่วนวิชาที่สอน 
แสดงเป็น badge/tag 3-5 ความสนใจ เช่น การท่องเที่ยว, การอ่านหนังสือ, กีฬา
(ปรับให้ตรงกับความสนใจจริงของเรา)
```

### รอบที่ 3: ตกแต่งให้สมบูรณ์

```
ช่วยทำให้หน้าเว็บดูเป็น professional มากขึ้น โดย:
1. เพิ่ม header ส่วนบนสุดที่มีพื้นหลังสีเข้ม
2. Footer ส่วนล่างแสดง "© 2568 [ชื่อของเรา]"
3. ทำให้ responsive ดูได้ดีบนมือถือด้วย
```
