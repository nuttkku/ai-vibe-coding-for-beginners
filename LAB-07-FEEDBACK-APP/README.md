## เราจะสร้างอะไร?

- มีฟอร์มให้กรอก: ชื่อ, หัวข้อ, ความคิดเห็น
- กดส่งแล้วแสดงความคิดเห็นในหน้าเดียวกัน
- เก็บข้อมูลในเบราว์เซอร์ (localStorage)
- รันด้วย Docker

## ขั้นตอนที่ 2: วางแผนกับ AI ก่อนเริ่มสร้าง

เปิด Cline แล้วส่ง Prompt นี้เพื่อให้ AI ช่วยวางแผนก่อน:

```
ฉันต้องการสร้างเว็บแอปพลิเคชัน "กล่องรับความคิดเห็น" สำหรับโรงเรียน
ตัวแอปต้องการ:
1. ฟอร์มรับ: ชื่อผู้ส่ง (ไม่บังคับ), หัวข้อ (dropdown: ข้อเสนอแนะ/ปัญหาที่พบ/คำชื่นชม), ข้อความ
2. ปุ่มส่ง
3. แสดงรายการความคิดเห็นทั้งหมดด้านล่าง
4. เก็บข้อมูลด้วย localStorage (ไม่ต้องมี backend)
5. ภาษาไทย ดีไซน์สะอาด

ช่วยบอกว่าจะต้องสร้างไฟล์อะไรบ้าง และแต่ละไฟล์ทำอะไร?
ยังไม่ต้องเขียนโค้ด แค่วางแผนก่อน
```

**ดูคำตอบ AI แล้วทำความเข้าใจ** — AI ควรบอกว่าต้องมีไฟล์ประมาณนี้:
- `index.html` — โครงสร้างหน้าเว็บ
- `style.css` — ดีไซน์และสี
- `script.js` — ตรรกะการทำงาน (รับข้อมูล, แสดงผล)
- `Dockerfile` — สำหรับรันด้วย Docker

## ขั้นตอนที่ 3: สร้าง HTML โครงสร้างหน้าเว็บ

ส่ง Prompt นี้ใน Cline:

```
ช่วยสร้างไฟล์ index.html สำหรับเว็บ "กล่องรับความคิดเห็น" ของโรงเรียน
โครงสร้างมีดังนี้:
- <head> มี title ภาษาไทย และ link ไปยัง style.css กับ script.js
- ส่วน header: หัวข้อ "📬 กล่องรับความคิดเห็น" และชื่อโรงเรียน
- ส่วนฟอร์ม (id="feedbackForm"):
  - input ชื่อผู้ส่ง (placeholder: "ชื่อของคุณ (ไม่บังคับ)")
  - select หัวข้อ: ข้อเสนอแนะ, ปัญหาที่พบ, คำชื่นชม, อื่นๆ
  - textarea ข้อความ (required, placeholder: "เขียนความคิดเห็นที่นี่...")
  - button ส่ง
- ส่วนแสดงผล: หัวข้อ "ความคิดเห็นทั้งหมด" และ div id="feedbackList"
ทุก label และ text เป็นภาษาไทย
```

คลิก Approve เมื่อ Cline ขอสร้างไฟล์

## ขั้นตอนที่ 4: สร้าง CSS สไตล์หน้าเว็บ

ส่ง Prompt นี้:

```
ช่วยสร้างไฟล์ style.css สำหรับเว็บกล่องรับความคิดเห็น
ต้องการ:
- สีหลัก: ม่วงหรือน้ำเงิน บน background สีขาวหรือเทาอ่อน
- ฟอร์มอยู่ตรงกลาง กว้างสูงสุด 600px
- input, select, textarea มีขอบโค้งมน, padding สวยงาม
- ปุ่มส่ง: สีเต็ม hover แล้วเข้มขึ้น ใช้ทั้งความกว้าง
- การ์ดความคิดเห็นแต่ละอัน: มี shadow เบาๆ มีขอบซ้ายสีหลัก แสดงหัวข้อ badge
- font-family ที่อ่านง่ายบน Windows
- Responsive บนมือถือด้วย
```

คลิก Approve

## ขั้นตอนที่ 5: สร้าง JavaScript ตรรกะการทำงาน

ส่ง Prompt นี้:

```
ช่วยสร้างไฟล์ script.js สำหรับเว็บกล่องรับความคิดเห็น
ฟังก์ชันที่ต้องการ:
1. เมื่อ page โหลด: ดึงข้อมูลจาก localStorage แล้วแสดงรายการความคิดเห็นทั้งหมด
2. เมื่อกด submit ฟอร์ม:
   - ตรวจสอบว่ากรอกข้อความแล้ว (required)
   - บันทึกข้อมูลลง localStorage (เป็น array ของ object)
   - แสดงผลใหม่ทันที
   - ล้างฟอร์มหลังส่ง
   - แจ้งเตือนว่าส่งสำเร็จ
3. แสดงแต่ละ feedback เป็น card มีข้อมูล: ชื่อ (หรือ "ไม่ระบุชื่อ"), หัวข้อ, ข้อความ, วันเวลาที่ส่ง

ใช้ JavaScript แบบ Vanilla (ไม่ต้องใช้ library ภายนอก)
```

คลิก Approve

## ขั้นตอนที่ 6: ทดสอบในเบราว์เซอร์

1. คลิกขวาที่ `index.html` → **"Reveal in File Explorer"**
2. ดับเบิลคลิก `index.html` เพื่อเปิดในเบราว์เซอร์
3. ทดสอบการทำงาน:
   - กรอกข้อมูลในฟอร์ม
   - กดปุ่มส่ง
   - ดูว่าความคิดเห็นแสดงด้านล่าง
   - Refresh หน้าเว็บ — ข้อมูลต้องยังอยู่

**ถ้ามีปัญหา:** บอก Cline ว่า "ทดสอบแล้วพบว่า [ปัญหาที่พบ] ช่วยแก้ให้ด้วย"

## ขั้นตอนที่ 9: Build และ Run ด้วย Docker

เปิด Terminal ใน VS Code แล้วรันตามลำดับ:

```bash
# Build Image
docker build -t feedback-app .

# Run Container
docker run -d -p 3000:80 --name feedback feedback-app
```

เปิดเบราว์เซอร์ไปที่: `http://localhost:3000`

ทดสอบว่าใช้งานได้เหมือนกันกับที่เปิดตรงจาก File Explorer

## ขั้นตอนที่ 10: Commit ด้วย Git Desktop

1. เปิด GitHub Desktop

5. คลิก **"Commit to main"**
