## 💡 Vibe Coding คืออะไร?

**Vibe Coding** คือการเขียนโปรแกรมในยุค AI ที่เราไม่ต้องจำโค้ดเลยสักบรรทัด

เราทำหน้าที่เป็น **"ผู้สั่งการ"** — บอก AI ว่าต้องการอะไร เป็นภาษาคนธรรมดา  
AI ทำหน้าที่เป็น **"ผู้เขียนโค้ด"** — แปลงความต้องการออกมาเป็นโปรแกรมให้

```
พิมพ์ "ทำเว็บโรงเรียน สีน้ำเงิน ภาษาไทย"
              ↓
    AI เขียนโค้ดให้ทันที
              ↓
   เราดู → แก้ไข → บันทึก
```

## 👥 หลักสูตรนี้เหมาะกับใคร?

- 👩‍🏫 **ครูคอมพิวเตอร์** ที่ไม่ได้เขียนโปรแกรมมานาน
- 💻 **ผู้ที่ใช้คอมพิวเตอร์เป็น** แต่ไม่มีพื้นฐานการเขียนโค้ด
- 🏫 **ผู้ที่ต้องการนำไปสอนนักเรียน** หรือสร้างสื่อการสอนดิจิทัล

> ไม่ต้องรู้จักโค้ดมาก่อนเลย — เริ่มได้ทันที

## 🔄 Loop การทำงานหลัก

หัวใจของ Vibe Coding มี 4 ขั้นตอน วนซ้ำจนกว่าจะพอใจ:

```
┌─────────────────────────────────────────────────────────┐
│                                                         │
│   1️⃣ บอก AI  →  2️⃣ ดูผล  →  3️⃣ แก้ไข  →  4️⃣ บันทึก   │
│        ↑___________________________________|            │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

1. **บอก AI** — พิมพ์ความต้องการใน Cline เป็นภาษาคน
2. **ดูผล** — เปิด Browser ดูว่าได้ตามที่ต้องการไหม
3. **แก้ไข** — สั่ง AI ปรับ ไม่ต้องเริ่มใหม่ทั้งหมด
4. **บันทึก** — Commit งานด้วย GitHub Desktop

## 📖 หลักการสำคัญ 3 ข้อ

### 1. 🚫 ห้ามพิมพ์โค้ดเอง

> **"บอก AI — แล้ว AI จะเขียนให้"**

ทุกบรรทัดของโค้ดในหลักสูตรนี้เกิดจากการบอก AI ผ่าน Cline ทั้งสิ้น ไม่มีการพิมพ์โค้ดเองแม้แต่บรรทัดเดียว

### 2. ♻️ Iterate ไม่ใช่ Restart

เมื่อผลลัพธ์ไม่ตรงใจ → สั่งให้ AI ปรับต่อ ไม่ใช่เริ่มใหม่

```
"ดีแล้ว แต่ช่วยเปลี่ยนสีปุ่มเป็นสีเขียว และเพิ่ม emoji หน้าชื่อแต่ละส่วนด้วย"
```

### 3. 💾 Commit บ่อย = ปลอดภัยเสมอ

ทุกครั้งที่งานทำงานได้ → Commit ทันที เพราะ Rollback ทำได้เฉพาะ Commit ที่บันทึกไว้แล้ว

## 🔑 Prompt Engineering — หัวใจของ Vibe Coding

Prompt ที่ดีมี 3 ส่วน:

```
บริบท:   "ฉันเป็นครูวิทยาศาสตร์ ป.5..."
เป้าหมาย: "...ช่วยสร้างเว็บ HTML ควิซ 5 ข้อเรื่องระบบสุริยะ..."
ข้อจำกัด: "...ภาษาไทย สีน้ำเงิน ไม่ต้องใช้ Library ภายนอก"
```

| ❌ Prompt ไม่ดี | ✅ Prompt ที่ดี |
|---|---|
| `"สร้างเว็บ"` | `"สร้างหน้าเว็บโรงเรียน สีน้ำเงินขาว ภาษาไทย"` |
| `"ทำฟอร์ม"` | `"ฟอร์มรับสมัคร มีชื่อ-ชั้น-เบอร์โทร ปุ่มสีเขียว"` |
| `"แก้ Error"` | `"Error: feedbackList is not defined บรรทัด 15 ช่วยแก้"` |
