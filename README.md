# Vibe Coding for Beginners
**หลักสูตรอบรม: สร้างแอปพลิเคชันด้วย AI โดยไม่ต้องพิมพ์โค้ดเอง**

ระยะเวลา: **2 วัน** (วันละ 6 ชั่วโมง)
กลุ่มเป้าหมาย: ครูคอมพิวเตอร์ และผู้ที่ต้องการสร้างแอปพลิเคชันด้วย AI

---

## เครื่องมือที่ใช้ในการอบรม

| เครื่องมือ | หน้าที่ | ดาวน์โหลด |
|---|---|---|
| VS Code | โปรแกรมแก้ไขโค้ด (Code Editor) | code.visualstudio.com |
| GitHub Desktop | จัดการเวอร์ชันด้วย GUI ไม่ต้องพิมพ์คำสั่ง | desktop.github.com |
| Docker Desktop | รันแอปในสภาพแวดล้อมที่ควบคุมได้ | docker.com/products/docker-desktop |
| Ollama | รัน AI Model บนเครื่องตัวเอง (ออฟไลน์) | ollama.com |
| Cline | AI Coding Assistant Extension ใน VS Code | ติดตั้งใน VS Code Extensions |

---

## โครงสร้าง LAB

```
LAB-01-SETUP/               ← ติดตั้ง VS Code, GitHub Desktop, Docker, Ollama, Cline
LAB-02-FIRST-CHAT/          ← คุยกับ AI ครั้งแรกผ่าน Cline
LAB-03-PROMPT-ENGINEERING/  ← เรียนเขียน Prompt ที่มีประสิทธิภาพ
LAB-04-FIRST-HTML/          ← สร้างหน้าเว็บแนะนำตัวด้วย AI
LAB-05-GIT-DESKTOP/         ← บันทึกงานด้วย GitHub Desktop
LAB-06-DOCKER/              ← สร้าง Dockerfile และรันด้วย Docker
LAB-07-FEEDBACK-APP/        ← Workshop: สร้างเว็บรับความคิดเห็นตั้งแต่ศูนย์
LAB-08-DEBUG-ROLLBACK/      ← แก้บัคด้วย AI + ย้อนเวลากลับด้วย Git Desktop
```
